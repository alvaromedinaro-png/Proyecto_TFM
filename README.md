# Proyecto TFM

Repositorio base del Trabajo Fin de Master.

## Estructura inicial

- `docs/`: documentacion y entregas.

## Primeros pasos

1. Clona el repositorio.
2. Revisa la documentacion en `docs/`.
3. Define el stack tecnico y crea la estructura especifica (`src/`, `tests/`, etc.) cuando lo tengas claro.

## Buenas practicas

- Mantener commits pequenos y descriptivos.
- Documentar decisiones importantes en `docs/`.
- No subir secretos ni credenciales.
